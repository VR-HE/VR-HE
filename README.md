# VR-HE

A Unity prototype for exploring ISP hubsites and headends with Gaussian splats and editable rack/equipment information.

> **ON HOLD from November 11, 2026.** Arlen paused development after learning that his company already uses NetBox. Its actual coverage and installed extensions need evaluating before he decides whether VR-HE continues. Development resumes only on his explicit instruction.

[PR #1](https://github.com/VR-HE/VR-HE/pull/1) and [PR #2](https://github.com/VR-HE/VR-HE/pull/2) were closed without merging because the project is on hold. The synthetic browser prototype supports navigation and local equipment/description editing. Capture, phone/Quest builds, production security, a backend and spreadsheet synchronization remain unimplemented. Using NetBox as a backend is a possible future direction, not an approved architecture.

GitHub does not contain the ignored demo ZIPs, raw results or saved browser records. See the checkpoint before cleaning up local files.
