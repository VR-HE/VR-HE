                How to use this demo

                1. Give the view your keyboard

                Click once on the 3D view. While a panel or text box is open, the view ignores the keyboard and mouse, so typing never moves you.

                2. Move

                W / ↑ forward, S / ↓ back, A / ← step left, D / → step right. To turn, drag on the view (3). Hold Shift to go faster. Racks and walls stop you.

                3. Look around

                Hold the left mouse button on the view and drag. For game-style looking press M (or Capture mouse): the pointer disappears and a small cross marks the centre. Press Esc to get the pointer back.

                4. Camera height and reset

                Q raises the camera, E lowers it. X (or Reset view) restores the normal height and a level view; in third person it also puts the camera back behind the figure.

                5. First or third person

                V switches views. Third person shows a plain placeholder figure about 1.73 m tall as a rough size cue; drag to circle around it and use the mouse wheel to zoom.

                6. Select and open a rack

                Point at a rack: a white outline appears. Click it: the outline turns cyan and its name shows above it. Then right-click it, press Enter, or press Open selected record. No mouse aiming needed: open Equipment list (L), which lists every rack and the equipment in it.

                7. Rack note

                The Rack note is about the whole rack, not one device. Type, then press Save note (or Ctrl+Enter). Each rack keeps its own note.

                8. Equipment in a rack

                A rack can hold many pieces of equipment. Under Add equipment, type a name and the rack units (RU) it fills, then press Add equipment. RU 1 is the bottom position. A device that fills two units, for example RU 20 and 21, is one item: enter From RU 20 to RU 21. If two items share a unit you see a warning; this demo does not record front or rear mounting, so check the numbers. Rack sizes here are a demo assumption (42 RU), not measured from the 3D picture. Open an item from the rack or from the Equipment list; its rack is selected in the view.

                9. Descriptions of one item

                A new item starts with one empty description with no name. + Add description adds another, to that item only. Give each description a name from its list (such as Serial number) or leave it unnamed. Two items can both use Serial number, each with its own text. The arrows change the order. Remove only works on an empty description: text is never deleted here. Press Save (or Ctrl+Enter) to keep your changes.

                10. Description names: add, rename, remove

                Open Description names in the toolbar, or choose Manage names… in an item. Add name puts a name in every item's list but changes no item. Rename fixes a spelling everywhere the name is used; the text stays the same. Remove… always asks for a replacement (an existing name or a new one): every description with the old name gets the replacement and keeps its text, then the old name leaves the list. If an item already has a description with the replacement name, both are kept. A name can't be removed without a replacement.

                11. Save, reopen and restart

                Close a panel and open it again, reload the page, or close the browser and start the demo again with the same launcher: everything you saved returns. Rack notes saved with the earlier demo version are carried over, and the earlier copy is kept unchanged.

                12. What is saved, and where

                LOCAL DEMO DATA only: synthetic racks, equipment and names in this browser profile on this computer. Nothing leaves this computer, and nothing goes to a spreadsheet or company system; renaming or removing a name never touches a spreadsheet column. Saved data & export downloads a JSON copy or resets the demo data. The demo's own test server on this computer keeps a copy of each export, with timings and console messages, in its results folder.

                Settings
